# SSH Manager TUI

Терминальный менеджер SSH-подключений на Go. Хранит хосты и профили,
поддерживает вкладки, SFTP, проброс портов и встроенную SSH-консоль.

## Установка

Установщик сам выберет `amd64`/`arm64`, проверит SHA-256 и установит команду
в `/usr/local/bin`. При необходимости будет запрошен пароль `sudo`.

### Linux

```bash
curl -fsSL https://raw.githubusercontent.com/LaboratoryNull/SSH-Manager-TUI/main/scripts/install-linux.sh | sh
sshm
```

### macOS

```bash
curl -fsSL https://raw.githubusercontent.com/LaboratoryNull/SSH-Manager-TUI/main/scripts/install-macos.sh | sh
sshm
```

### Windows

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/LaboratoryNull/SSH-Manager-TUI/main/scripts/install-windows.ps1 | iex
sshm
```

## Возможности

- SSH по паролю или ключу с проверкой host key;
- повторный запрос и сохранение нового пароля после ошибки авторизации;
- несколько независимых подключений во вкладках;
- загрузка, скачивание и управление файлами через SFTP;
- Local, Remote и Dynamic SOCKS5-пробросы портов;
- автоматический поиск серверов в истории Bash, Zsh и Fish;
- группы хостов и переиспользуемые профили пользователя;
- автоматическое переподключение;
- проверка новой версии и обновление прямо из интерфейса;
- разделение экрана на 2–4 терминала с задержкой до сервера и временем
  сессии в заголовке каждой панели;
- палитра команд (`Ctrl+K`, в сессии `Esc` `K`) и темы оформления: Corporate
  (по умолчанию), Steam, Elysium и другие.

## Как пользоваться

Откройте `sshm` и начните печатать: список серверов фильтруется сразу.

- `Enter` — подключиться к выбранному серверу;
- чтобы подключиться к новому серверу, введите адрес (`deploy@example.com`,
  `host:2222` или вставьте команду `ssh -p 2222 user@host`) и нажмите `Enter`;
  после успешного входа сервер сохранится сам;
- серверы из истории Bash, Zsh и Fish появляются в списке автоматически;
- `Ctrl+K` — все команды: изменить, переместить в группу, удалить, профили,
  тема и другие. Рядом с каждой командой показано её сочетание клавиш;
- `Ctrl+N` — новый сервер через форму, `Ctrl+E` — изменить, `Del` — удалить.

В подключении все клавиши (`Ctrl+W`, `Ctrl+T`, `F1`, `Alt+…`) уходят на сервер —
в bash, nano, mc или консоль роутера. Команды менеджера набираются после `Esc`:

- `Esc` `K` — все команды;
- `Esc` `B` — показать или скрыть файлы (SFTP);
- `Esc` `T` / `Esc` `W` — новая вкладка / закрыть вкладку, `Esc` `←`/`→` или
  `Esc` `1…9` — переключить вкладку;
- `Esc` `S` — разделить экран: добавить рядом открытую сессию или сервер
  (до 4 терминалов), `Esc` `Z` — развернуть панель, `Esc` `←`/`→` — фокус;
- `Esc` `P` — пробросы портов;
- `Esc` `Q` — отключиться.

На macOS интерфейс автоматически показывает системно совместимые сочетания.

## Обновление

```bash
sshm update --check
```

Также приложение проверяет обновления при запуске и показывает кнопку установки.
